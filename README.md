# Lucia · لوتشيا — Café Website

A bespoke single-file website for **Lucia Café** (لوتشيا), an Italian-inspired specialty coffee & bakery in Al Rawdah, Riyadh.

## View it

- **Locally in Chrome** — just double-click `index.html`. No server needed.
- **Live on GitHub Pages** — enable Pages in repo settings (branch: this one, folder: `/`).

## What's inside

- Cinematic loader with steaming-cup animation
- Custom cursor + scroll progress + click ripples
- Parallax hero, marquee strip, paper-grain texture
- Filterable menu with real items (prices in SR) — each with its own photo, EN + AR name, calories, hover tilt
- "Signature" feature card (Lucia French Toast)
- Auto-rotating guest reviews
- Visit Us section with embedded Google Map, hours, Instagram + Maps links
- Mobile-friendly, no build step, no dependencies (just Google Fonts + Unsplash images)
